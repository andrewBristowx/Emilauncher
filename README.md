# EmiLauncher

Launcher propio para **Emipokemon / Cobbleverse**.

Este repositorio se usará para construir un launcher actualizable con identidad visual propia, soporte para el modpack personalizado y distribución mediante GitHub.

La primera etapa se centra únicamente en la experiencia visual del launcher. Las funciones de autenticación Microsoft, sincronización real del modpack y lanzamiento de Minecraft se incorporarán en etapas posteriores.
